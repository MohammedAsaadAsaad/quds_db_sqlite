SelectQueryBuilder

SelectQueryBuilder<T> class abstract

Abstract builder for SELECT queries with support for joins and aggregates.

Example:

queryBuilder
  .from(notesProvider)
  .innerJoin(tagsProvider, (note, tag) => note.tagId.equals(tag.id))
  .where((note, tag) => note.isActive.isTrue)
  .orderBy((note, tag) => note.createdAt.descOrder)
  .limit(10)
  .build()
