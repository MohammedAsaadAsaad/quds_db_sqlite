TableProvider

TableProvider<T extends DbModel> class abstract

Abstract base class for database table providers.

Implementers should provide database-specific CRUD and query operations. This interface defines the contract that all implementations must follow.

Supports:

  • Basic CRUD operations (insert, update, delete, select)
  • Query building with JOINs
  • Aggregations and GROUP BY
  • Filtering, ordering, and pagination
Implementers

  • SqliteTableProvider
