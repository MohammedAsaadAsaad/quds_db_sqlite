Quds DB SQLite ⚡️

A high-performance, strictly-typed, and fully automated SQLite implementation for the quds_db_interface.

Forget writing raw SQL strings, handling manual schema migrations, or worrying about passing transaction contexts. Quds DB SQLite handles it all automatically using a sophisticated "No-SQL" Dart approach.

🌟 Key Features

  • Strict Type Safety: All database operations (including queries, filtering, and ordering) use strongly-typed closures.
  • Automated Migrations: Automatically detects new fields in your DbModel and executes ALTER TABLE to add them.
  • Auto-Indexing: Flag fields as isIndexed, and the provider will automatically generate CREATE INDEX queries under the hood.
  • Magical Transactions: Execute block operations in a Zone-based transaction without ever passing a Transaction object to your provider methods!
  • Native Pagination: Easily query large data sets with loadAllEntriesByPaging.
  • Complex Queries: Fully supports INNER JOIN, LEFT JOIN, and aggregates (SUM, MAX, MIN, AVG, COUNT).

🛠 Setup & Initialization

import 'package:quds_db_sqlite/quds_db_sqlite.dart';

// 1. Setup the Settings
final adapter = SqliteDatabaseAdapter();
await adapter.initialize(SqliteDatabaseSettings(
  dbName: 'my_database.db',
  version: 1,
));

final connection = await adapter.getConnection('my_database.db');

// 2. Initialize your Provider (Automatically Migrates & Indexes!)
final tasksProvider = TaskProvider(connection, () => TaskModel(), 'Tasks');
await tasksProvider.initialize();

📝 Defining Models

Your models should extend StandardDbModel and define their fields statically to allow the provider to map rows correctly.

class TaskModel extends StandardDbModel {
  final title = StringField(columnName: 'title', notNull: true);
  final isCompleted = BoolField(columnName: 'isCompleted', defaultValue: false);
  final priority = IntField(columnName: 'priority', defaultValue: 0, isIndexed: true); // Auto-Indexed!
  final tags = JsonField(columnName: 'tags'); // Supports native JSON encoding/decoding

  @override
  List<FieldDefinition>? getFields() => [title, isCompleted, priority, tags];
}

🔎 Pure-Dart Queries (No SQL)

With strict closure typing, your queries are robust and immune to SQL-injection syntax errors.

// Fetch all pending high-priority tasks
final urgentTasks = await tasksProvider.select(
  where: (t) => ConditionGroup(conditions: [
    t.isCompleted.equals(false),
    t.priority.greaterThan(5),
  ]),
  orderBy: (t) => [t.priority.descOrder],
  limit: 10,
);

// Pagination
final page = await tasksProvider.loadAllEntriesByPaging(
  pageQuery: DataPageQuery(page: 1, resultsPerPage: 20),
  orderBy: (t) => [t.id.ascOrder],
);
print('Total Pages: ${page.pages}');

🪄 Zone-Based Transactions

No more passing transaction objects down your widget tree or provider architecture!

Quds DB SQLite utilizes runZoned to implicitly inject the SQLite transaction context. Just wrap your operations in .transaction(), and all providers will magically utilize the transaction.

try {
  await connection.transaction(() async {
    final t1 = TaskModel()..title.value = 'Bulk Task 1';
    final t2 = TaskModel()..title.value = 'Bulk Task 2';

    // These natively execute within the transaction context!
    await tasksProvider.insertEntry(t1);
    await tasksProvider.insertEntry(t2);
    
    // If an error is thrown here, BOTH inserts are automatically rolled back!
  });
} catch (e) {
  print('Transaction Failed & Rolled Back!');
}
